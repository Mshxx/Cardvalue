CardValue v2

Recherche de cartes Pokémon + prix réels via PokeTrace
La recherche utilise le marché choisi. Les prix gradés nécessitent un accès PokeTrace Pro ou supérieur.
Important : cette V2 ne fabrique pas de prix. Elle affiche les données retournées par PokeTrace. Les données EU viennent notamment de CardMarket et les données US de TCGPlayer/eBay selon le marché et le plan. Les ventes eBay individuelles sont disponibles via l'endpoint « listings » du plan Scale.
